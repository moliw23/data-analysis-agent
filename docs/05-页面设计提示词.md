# 页面设计提示词（设计师交付 · Wave 2）

> 生成日期：2026-09-25 ｜ 依据：`docs/03-UIUX.md` + `src/design-tokens.css`（453 行，唯一 Token 来源）
> 通用约束（每页适用）：① 图标一律 lucide-react（尺寸 16/20/24，strokeWidth 跟 `--icon-stroke`）；② 颜色/间距/字号/圆角/阴影 100% 引用 Token，组件内零字面量（`#fff/#000` 除外）；③ 弹跳缓动禁用；④ 删除操作一律二次确认；⑤ 明细数据不出本机的文案基调，不用"智能体/对话式"措辞。

---

## P-01 双形态状态条 ModeBanner（新增，全局）

顶栏下方 32px 细条。在线态：左侧圆点（`--success`）+「本地服务已连接」+ 档位徽标 + 降级能力徽标列表（如「知识库·未启用」），右侧「说明」按钮。离线态：圆点（`--n-400`）+「本地模式」+ 一句话"AI 记忆、知识库、服务端调度不可用" + `重试`文字按钮 + `启动指引`。checking 态不渲染。样式：`--surface` 底 + `--border` 下边线，徽标 `--radius-pill`、`--n-100` 底、11px。

## P-02 隐私档位指示器 PrivacyIndicator（新增，顶栏常驻）

顶栏右侧按钮：`ShieldCheck` 20px + 档位名（strict/standard/full，小写字距 0.02em）。点击展开 264px popover（`--elev-2` + `--radius-md`）：① 当前档位标题+一句话含义；② 三档列表（名称 + 一句语义 + 受控能力数），**中性配色，仅当前档 `--accent` 描边，禁止红黄绿**；③ 当前档被阻断的能力清单（4030 语义）；④ 底部「去设置」按钮（跳 settings）。交互：Esc/点击外部关闭；`aria-expanded`。

## P-03 模型接入 SettingsPanel（改造：顶部插入档位区块）

现有视图顶部第一区块改为「隐私与数据」：左侧档位三选一 seg 控件（沿用 `.seg`，宽度一致不随字数伸缩）；右侧只读说明文案（两行内说明当前档数据边界）。变更时弹二次确认（`X-Local-Confirm` 语义映射到 UI），成功后 toast「隐私档位已切换」。下方保留现有模型接入表单，布局不动。

## P-04 知识库 KnowledgeView（新增，Wave 3 实现本波只出提示词）

左侧知识库列表卡（名称、文档数、分块数、`index_status` 徽标：ready=`--success` / 处理中=`--warn` / 需重建=`--danger`——仅状态语义可用语义色，档位本身禁止）；右侧详情：文档表（文件名/大小/状态/入库档位徽标 `ingested_mode`）+ 上传区（拖拽 `--radius-md` dashed 边框）。上传前必须渲染合规提示条：「文档分块会随提问发送给所配模型服务」，黄色 `--warn` 左边线提示条而非弹窗。检索框 + Top-5 结果列表（每条含来源文件名+片段高亮）；降级检索时结果区顶部固定「关键词模式」徽标。

## P-05 记忆面板 MemoryPanel（新增，Wave 3）

设置页内区块：条目列表（内容摘要、scope 徽标、weight 数字用 `--font-mono`、过期时间）；每条行尾 `Pencil`/`Trash2` 图标按钮（40px 热区）；顶部「记忆总开关」switch（关闭后列表置灰并显示"已关闭，不再注入"）。空态：一句话说明 + 示意图（线条风，不用插画）。

## P-06 命令面板 CommandPalette（新增，Wave 3）

Cmd/Ctrl+K 唤起，屏幕水平居中距顶 96px，宽 560px，`--elev-3` + `--radius-lg`。输入框置顶无边框；结果分组：视图跳转 / 数据集 / 模板；每行 `icon 16px + 名称 + 副标题(--muted 12px)`；↑↓ 选择、Enter 确认、Esc 关闭；选中行 `--accent-50` 底。数据不足 3 条时不显示分组头。

- [ ] 单文件 ≤300 行；删除类操作均有二次确认
