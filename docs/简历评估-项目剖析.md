**定位建议**：把它作为「独立全栈式前端项目 / 数据可视化方向」的代表作，而不是"大型系统"。卖点是**宽度的技术广度 + 隐私优先的设计取舍**，而非业务深度。

### 6. 技术亮点（真实可讲 ★★★★★）
以下都是"能当场演示、能说清取舍"的硬货：
- 🔥 **大文件流式解析**：Web Worker + `File.stream()` + 逐字符 CSV 状态机 + 进度/取消/采样；实测 **56 万行 / 15MB ≈ 8.9s**，规避大文件 OOM
- 🔥 **Text-to-SQL 闭环**：LLM 生成 SQL → 只读 SELECT 白名单校验（拦截 DDL/DML/多语句）→ alasql 真实执行 → 结果表+图表；未配 LLM 时规则引擎降级
- 🔥 **跨表语义模板**：`matchTemplate` 按"角色"而非列名绑定，实现分析经验跨数据集复用，模板不含原始数据（隐私）
- 🔥 **ECharts 暗色主题适配**：CSS 变量 + 主题防闪烁 + 图表重绘
- 🔥 **SQL 安全白名单**：列名白名单 + AS 别名/字符串/表名正确豁免 + 中文列名自动反引号
- 🔥 **多表关联自相关修复**：同源列（`quantity`/`quantity_2`）去重，避免热力图出现 ±1.0 无意义系数（说明你有"数据正确性"意识）

## 三、简历呈现建议（话术模板）

**项目名**：一站式隐私优先数据分析 Agent（前端）
**角色**：独立开发者（需求/设计/编码/测试全负责）
**技术栈**：React 18 + Vite + ECharts + alasql + Web Worker + IndexedDB + OpenAI 兼容 LLM API

**一句话定位**：
> 纯前端、零部署的数据分析工具，用户数据全程不出浏览器；支持从文件/API/数据库接入，经流式解析、清洗、质量诊断后，自动生成看板、图表、Text-to-SQL 问答与多格式报告。

**亮点条（量化）**：
- 用 Web Worker + 流式解码将 15MB/56 万行 CSV 的解析耗时压到 ~9s 且主线程不卡顿
- 设计 Text-to-SQL 闭环，用只读 SQL 白名单拦截 100% 的 DDL/DML/多语句注入
- 动态分包使首屏 bundle 仅 ~355KB（alasql 511KB 按需加载）
- 实现跨表语义模板，使同一分析模板可复用至结构不同的数据集

**避坑话术**（被问测试/质量时）：
> "引擎层已落地 Vitest 单测 + ESLint 0 error，并把 engine 按职责拆分为 14 个模块；App.jsx 也已拆为控制器 + components/ 视图层（ECharts 基建与 9 个展示视图独立成文件）；全局状态抽到 Zustand，并补了 store 与六大视图组件的深度交互测试，目前共 94 项单测全绿，整体 src 行覆盖 56.7%，CI 跑 lint+test+build。"
> —— 主动提改进方向，比被问住强。
